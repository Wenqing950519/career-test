# Career Test｜職涯性格測驗

一個可以直接分享給朋友使用的輕量職涯網站，包含兩個頁面：

- **17 題小測驗**：用生活情境整理活動偏好、工作價值、工作情境、能力線索、內容領域與現實條件，完成後直接顯示探索方向。
- **履歷生成器**：填寫基本資料、教育背景、技能與三類經歷，即時預覽 A4 履歷，並可列印成 PDF 或匯出 JSON Resume。

## 隱私設計

網站沒有帳號、後端資料庫或瀏覽器持久化。所有作答與履歷內容只存在目前分頁的 React 記憶體中；重新整理或關閉分頁後即清空。下載測驗結果、JSON Resume 或另存 PDF 都由使用者主動觸發。

## 本機開發

```bash
npm install
npm run dev
```

開啟 `http://localhost:3000`，首頁會自動前往 `/quiz`。另一個頁面位於 `/resume`。

## 驗證

```bash
npm test
```

測試會重新建置網站，確認兩個頁面可伺服器渲染、題庫維持 17 題，且主要互動程式不含瀏覽器資料持久化呼叫。
